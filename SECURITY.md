# Security Policy

PlotterGraph is a standalone Processing sketch. It has no network features and only reads and writes files through the normal open/save dialogs or inside its own sketch folder.

## Supported versions

Only the latest release and the current `main` branch receive fixes.

## Reporting a vulnerability

If you find a security problem (for example, a crafted preset file that does something it shouldn't), please report it privately through GitHub's **[Report a vulnerability](https://github.com/Murphy23x/PlotterGraph/security/advisories/new)** form rather than opening a public issue.

Please include the steps to reproduce it and, if relevant, the file that triggers it. You can expect a first response within a couple of weeks. This is a hobby project, so there is no bounty.
